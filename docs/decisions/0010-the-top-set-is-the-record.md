# 0010. The top set is the record

- **Status:** accepted
- **Date:** 2026-10-11
- **Deciders:** David
- **Tenet invoked:** 5 (recording costs less than skipping)

## Context

Logging every set of every exercise is the cost that kept the log empty. The progression only needs the heaviest working set to decide the next load.

## Options considered

- **Log every set.** Complete; the most expensive habit in the app.
- **Log the top set per lift.** One entry per lift; the progression still has its input.

## Decision

Each lift records its top set (weight by reps). Back-off and warm-up sets are not required.

## Consequences

Logging a session is a handful of entries. What gets worse: volume per session is estimated from the plan, not measured.
