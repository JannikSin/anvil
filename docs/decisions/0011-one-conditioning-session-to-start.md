# 0011. One conditioning session a week to start; sessions as short as the volume allows

- **Status:** accepted
- **Date:** 2026-10-12
- **Deciders:** David
- **Tenet invoked:** 4 (attendance before perfection) over 1 (the plan covers the goal)

## Context

The programme prescribed three conditioning sessions a week (two Zone 2 runs and one interval
block, 120 to 150 aerobic minutes). None happened: the log holds no conditioning since the block
was written. Every lifting session is priced at about 50 minutes; David's stated budget is about
60, and he would rather it be shorter if the work still lands.

## Options considered

- **Keep three sessions.** The full aerobic prescription; it has not happened once.
- **One session a week, grown once it sticks.** Less aerobic work on paper; work that happens.
- **Drop conditioning.** Simplest; breaks tenet 1, which requires one conditioning session.

## Decision

One session a week, Saturday, later in the day: tennis, or a 25 to 30 minute outdoor run at a
conversational pace. A second session is added only once this one happens most weeks. The
2026-08-24 prescription stays in git history as the target to grow back toward.

Sessions stay at about 50 minutes, and shorter is better, on one condition: every major muscle
group is trained twice a week with enough hard sets to grow (the push, pull, legs rotation run
twice a week already does this). Time comes out of rest and exercise choice, never out of the
weekly sets per muscle group (Core Purpose P12).

## Consequences

The plan on screen is one the person can do. What gets worse: aerobic volume sits well under the
120 to 150 minute band, so the resting heart rate gains the old block promised come slower.
